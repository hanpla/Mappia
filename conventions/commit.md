# 커밋 메시지 규칙

## 태그

| 태그 | 설명 |
|------|------|
| `feat` | 새로운 기능 추가 |
| `fix` | 버그 수정 |
| `docs` | 문서 수정 (README 등) |
| `chore` | 사소한 작업 |
| `style` | 코드 포맷팅, 세미콜론 누락 등 (코드 변경 없는 경우) |
| `refactor` | 코드 리팩토링 |
| `test` | 테스트 코드 추가 및 수정 |

## 형식

```
태그: 제목

본문 (선택)
```

## 예시

```
feat: 로그인 페이지 구현

- 이메일/비밀번호 입력 폼 추가
- 유효성 검사 로직 적용
```
